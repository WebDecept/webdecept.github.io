Benchmarking Web Agent Safety under E-commerce Deceptive Interfaces

Zijing Shi1, Meng Fang2, Ling Chen1
1AAII, University of Technology Sydney  ·  2University of Liverpool
Paper (PDF) Code

TL;DR

We study how multimodal web agents behave when websites use deceptive interface patterns — the kinds of "dark patterns" widely seen in e-commerce. We release WebDecept, a lightweight, configurable plugin framework that injects controlled deceptive patterns into a reproducible shopping environment, and use it to measure agent safety end-to-end across product discovery, cart, and checkout.

Abstract

As autonomous web agents are increasingly deployed for real-world tasks, ensuring their safety has become a critical concern. We study web agent behavior under realistic deceptive interfaces in the e-commerce domain and introduce WebDecept, a lightweight, configurable plugin framework that enables controlled injection of deceptive interface patterns into existing web environments. Using WebDecept, we instantiate seven deceptive patterns commonly seen on the open web — including targeted advertisements, domain redirection, and shopping manipulation — and inject them into the frontend during task execution to perform controlled evaluation of multiple multimodal web agents. Our results show that current web agents are highly susceptible to multiple classes of deceptive interfaces, and that prompt-based safety constraints are often insufficient to mitigate these failures. We further analyze how the design choices of deceptive patterns influence the success of such manipulations, highlighting safety challenges that should be addressed as web agents are scaled toward real-world deployment.

Deceptive Patterns

WebDecept instantiates seven configurable deceptive patterns, grouped into three families:

  • Misleading UI elements — pop-up message, banner message, and their personalized (LLM-generated, goal-conditioned) variants.
  • Domain redirection — silently rewrites the hyperlink behind the agent's next optimal action, exposed only via the accessibility tree.
  • Shopping manipulations — cart add-ons (items stealthily added at checkout) and price drift (subtle gaps between itemized and total prices).

Code & Resources

Code is on GitHub: github.com/WebDecept/WebDecept. The framework is built on top of the shopping environment of VisualWebArena (OneStopShop) and can be readily integrated into other web benchmarks.
